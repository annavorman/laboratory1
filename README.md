## Метод

Кинематика — готовая модель `DiffDrive` из `robotics-course`; движение к цели — готовый
`PIDController`. Самостоятельно реализованы: виртуальный дальномер на 9 лучей
в секторе ±90° (пересечение луча с окружностью в конфигурационном пространстве),
конечный автомат `IDLE → RUN → AVOID → GOAL/FAULT` с гистерезисом 1.6 и выдержкой
0.3 с, закон обхода методом свободного сектора, цикл моделирования с шагом 0.05 с
и расчёт метрик.

## Вывод

1. Цель достигнута: автомат завершил работу в состоянии GOAL за 41.45 с модельного времени. 
Робот прошел 11.954 м при прямом расстоянии 12.021 м, то есть коэффициент извилистости составил 0.994.
2. Автомат выполнил 18 переходов; в состоянии AVOID робот провёл 57% шагов. 
Минимальный зазор до поверхности препятствия — 0.267 м при радиусе корпуса 0.15 м , то есть столкновения не было с запасом. 
3. Порог AVOID. В нашем эксперименте разброс оказался небольшим: кратчайший путь 
(11.924 м) получен при пороге 0.88 м, 
наибольший (11.979 м) — при пороге 0.33 м, разница около
 0.5%.
4. Параметры варианта 6: скорость 0.55 м/с, дальность датчика 
1.8 м, порог 0.55 м, 4 препятствий. Дальность датчика задаёт
 горизонт планирования: чем она больше, тем раньше
   робот замечает препятствие и тем плавнее обход. Число препятствий определяет, сколько раз
   сработает AVOID и насколько вырастет извилистость.
